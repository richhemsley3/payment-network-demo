Guides

Six guides in the order an integration happens. Each says what you need first, shows every call with a sample, and hands off to what comes next.

Start from what you want to do

Three goals, each a path through the guides. The first step of each needs no account.

Accept a payment

  1. 1Get a tokenThe demo credentials, valid for an hour.
  2. 2Send an authorizationA test card, answered in 41 ms.
  3. 3Capture the holdWithin 7 days, in full or in part.
  4. 4Branch on the codeSoft and hard declines, and when to retry.

Receive events

  1. 1Read a deliveryWhat arrives, signed, within a second.
  2. 2Register an endpointOne URL for every event. Needs an account.
  3. 3Verify the signatureHMAC over the timestamp and the body.
  4. 4Handle retriesThree days of them, de-duplicated on the event id.

Certify and go live

  1. 1Who sends whatYour host sends the cases. The network watches.
  2. 2The case groupsGenerated from your configuration.
  3. 3Submit for validationOnce every case is seen and passing.
  4. 4ActivationThe same credentials, promoted to production.
