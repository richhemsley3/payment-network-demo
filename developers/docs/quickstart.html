Quickstart

A token, then your first authorization, on the sandbox. Ten minutes. The same message you already send, at a new endpoint.

Before you startA sandbox client id and secret from a free account, or the demo credentials below, which run on a shared sandbox and are rotated daily.DGN_ID=demo_9f2a  DGN_SECRET=demo_shared_secret

Get a token

Credentials exchange for an OAuth token valid for one hour. The libraries refresh it for you.

curl -X POST https://sandbox.api.dgn.com/oauth/token \
  -u "$DGN_ID:$DGN_SECRET" \
  -d grant_type=client_credentials
import { Network } from "@dgn/node";
const dgn = new Network({ clientId: process.env.DGN_ID, clientSecret: process.env.DGN_SECRET, env: "sandbox" });
// the client fetches and refreshes the token
import dgn
client = dgn.Network(client_id=os.environ["DGN_ID"], client_secret=os.environ["DGN_SECRET"], env="sandbox")

Send your first authorization

Amounts are in minor units. 5820 is $58.20. The card is a test card; the response is the outcome it is built for.

Request
curl -X POST https://sandbox.api.dgn.com/acceptance/v1/authorizations \
  -H "Authorization: Bearer $TOKEN" \
  -H "Idempotency-Key: 7c9e6679-7425-40de-944b-e07fc1f90ae7" \
  -d '{ "amount": 5820, "currency": "USD", "merchant_id": "mch_demo", "pan": "6011330000000005", "entry_mode": "contactless" }'
const auth = await dgn.authorizations.create({
  amount: 5820, currency: "USD", merchantId: "mch_demo",
  pan: "6011330000000005", entryMode: "contactless"
});
auth = client.authorizations.create(
  amount=5820, currency="USD", merchant_id="mch_demo",
  pan="6011330000000005", entry_mode="contactless")
Response
{
  "id": "auth_71ab3c",
  "decision": "approved",
  "response_code": "00",
  "approved_amount": 5820,
  "avs": { "street": "Y", "postal": "Y" },
  "issuer_ms": 41,
  "score": 22
}

Try a decline

Change the card. 6011 3300 0000 0872 answers insufficient funds: a 200 with decision: declined and response_code: 51. A decline is an answer, not an error.

Capture it

An approval is a hold. Capture moves it into the day's clearing file. Capture within 7 days, in full or in part.

curl -X POST https://sandbox.api.dgn.com/acceptance/v1/captures \
  -H "Authorization: Bearer $TOKEN" -H "Idempotency-Key: $(uuidgen)" \
  -d '{ "authorization_id": "auth_71ab3c", "amount": 5820 }'
await dgn.captures.create({ authorizationId: auth.id, amount: 5820 });
client.captures.create(authorization_id=auth.id, amount=5820)

Receive the event

Every decision arrives at an endpoint you register as authorization.decisioned, signed, within a second. The CLI forwards events to your machine before you have a URL.

dgn events listen --forward-to localhost:4000/dgn/events
