Receive events

Events are sent to an endpoint you register, over mutual TLS, signed on every delivery, and retried for three days. Nothing here is a poll.

Before you startAn HTTPS URL that accepts POST and returns 2xx within 10 seconds, or the CLI forwarding to your machine. Registering a URL needs an account. Reading this page does not.

How a delivery happens

The network posts, you answer, the portal keeps every attempt. Your answer decides whether there is another.

Register an endpoint

In the Developer Portal, Webhooks, Add endpoint: a URL, the events it takes, per environment. Each endpoint has its own signing secret, shown once. Or forward to your machine first.

dgn events listen --forward-to localhost:4000/dgn/events
# prints the signing secret for this session

What arrives, and what you answer

A POST with two headers you read and a JSON body you keep raw until the signature is checked. The answer is a status line.

Verify the signature

Four steps, in constant time, before anything is trusted.

  1. 1
    Split the headert is the timestamp the network signed at. v1 is the signature. Ignore any other scheme.
  2. 2
    Build the signed payloadThe timestamp, a period, the raw body. The raw bytes, before any framework parses them.
  3. 3
    Compute HMAC-SHA256Key: the endpoint's secret. Message: the signed payload. Hex encoded.
  4. 4
    Compare, then check the clockA constant-time comparison against v1. Reject anything whose t is older than five minutes.
import crypto from "node:crypto";
app.post("/dgn/events", express.raw({ type: "*/*" }), (req, res) => {
  const [t, v1] = req.get("DGN-Signature").split(",").map(p => p.split("=")[1]);
  const mac = crypto.createHmac("sha256", process.env.DGN_WEBHOOK_SECRET).update(t + "." + req.body).digest("hex");
  if (!crypto.timingSafeEqual(Buffer.from(mac), Buffer.from(v1)) || Date.now()/1000 - t > 300) return res.sendStatus(400);
  res.sendStatus(200);  // answer first, then do the work
  handle(JSON.parse(req.body));
});
import hmac, hashlib, time
def verify(sig, body, secret):
    t, v1 = [p.split("=")[1] for p in sig.split(",")]
    mac = hmac.new(secret.encode(), f"{t}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(mac, v1) and time.time() - int(t) < 300

Deliveries are at least once and in no promised order. De-duplicate on the event id, and read created when order matters.

Rolling a secret

Roll it if it leaks or when someone with access leaves. For 24 hours both secrets are valid and every delivery carries a signature for each, so you can switch your verifier at any point in the window.
