Receive events

Events are sent to an endpoint you register, over mutual TLS, signed on every delivery, and retried for three days. Nothing here is a poll.

Before you startAn HTTPS URL that accepts POST and returns 2xx within 10 seconds, or the CLI forwarding to your machine. Registering a URL needs an account; reading this page does not.

Verify the signature

Compute an HMAC-SHA256 over the timestamp, a period, and the raw body, with the endpoint's secret. Compare in constant time. Reject anything older than five minutes. Answer 2xx first, then do the work.

import crypto from "node:crypto";
app.post("/dgn/events", express.raw({ type: "*/*" }), (req, res) => {
  const [t, v1] = req.get("DGN-Signature").split(",").map(p => p.split("=")[1]);
  const mac = crypto.createHmac("sha256", process.env.DGN_WEBHOOK_SECRET).update(t + "." + req.body).digest("hex");
  if (!crypto.timingSafeEqual(Buffer.from(mac), Buffer.from(v1)) || Date.now()/1000 - t > 300) return res.sendStatus(400);
  res.sendStatus(200);  // answer first, then do the work
  handle(JSON.parse(req.body));
});
import hmac, hashlib, time
def verify(sig, body, secret):
    t, v1 = [p.split("=")[1] for p in sig.split(",")]
    mac = hmac.new(secret.encode(), f"{t}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(mac, v1) and time.time() - int(t) < 300

Retries

Anything but a 2xx within 10 seconds is retried, backing off from one minute to one hour, for three days. Deliveries are at least once: handle the same event id twice. After three days the endpoint is marked failing and an alert says so. Retry now from the delivery in the portal.

Rolling a secret

Roll it if it leaks or when someone with access leaves. The previous secret stays valid for 24 hours, and every delivery in that window carries a signature for each.
