Reference

API reference

JSON over HTTPS. Amounts in minor units. Times in RFC 3339, UTC. Every response carries a request id and round_trip_ms. Eight endpoints and six events carry the whole network.

https://sandbox.api.dgn.com
OpenAPIPostman

Basics

Authentication

Every call carries a bearer token from your client id and secret, valid for one hour. Mutual TLS is required in certification and production. One set of credentials is promoted through the environments by the network.

curl -X POST https://sandbox.api.dgn.com/oauth/token -u "$DGN_ID:$DGN_SECRET" -d grant_type=client_credentials
# { "access_token": "…", "token_type": "bearer", "expires_in": 3600 }
const dgn = new Network({ clientId, clientSecret, env: "sandbox" }); // refreshes for you
client = dgn.Network(client_id=..., client_secret=..., env="sandbox")

The envelope

JSON over HTTPS. Amounts are integers in minor units. Times are RFC 3339 in UTC. Ids are prefixed by object: auth_, cap_, tok_, dsp_, stl_, evt_. Every response carries request_id and round_trip_ms.

Idempotency

Send Idempotency-Key on any POST. The same key within 24 hours returns the original response. A key in flight returns 409. See Errors and idempotency.

Errors

A decline is a 200 with a response_code. A request that could not be processed is a 4xx or 5xx with type, message and request_id. Every code and type.

Versioning

The version is in the path. Supported for 24 months after its successor ships. Additive changes are announced in the changelog without a version change.

Pagination

Lists return up to 100 objects and a next_cursor. Pass it as cursor to continue. Lists are newest first.

Acceptance

The Authorization object

The issuer's response to an authorization request. Carries the decision, the response code, the score, and timing.

idstring

auth_ followed by six hex characters.

decisionenum

approved, partial, declined, stand_in.

response_codestring

The issuer's code. 00 is approved. Every code.

approved_amountinteger

Minor units. Less than amount on a partial approval.

avsobject

street and postal, each Y, N or U.

scoreinteger

0 to 100. Network risk signal. score_reasons lists what moved it.

answered_byenum

issuer, or network on a stand-in.

issuer_msinteger

How long the issuer took.

POST/acceptance/v1/authorizations

Authorize a transaction

Request authorization from the issuer. Answered within 500 ms, or by stand-in rules you set.

What you send

amountintegerRequired

Minor units. 5820 is $58.20.

currencystringRequired

ISO 4217. Settlement currency is set on your account.

merchant_idstringRequired

Your merchant identifier, as registered.

pan_tokenstringOptional

A network token, or pan if you hold the data yourself. One of the two.

entry_modeenumOptional

contactless, chip, magstripe, ecommerce, keyed.

avsobjectOptional

street and postal to verify.

What comes back

An Authorization object. 200 for any decision. 4xx when the request could not be processed.

Request
curl -X POST https://sandbox.api.dgn.com/acceptance/v1/authorizations \
  -H "Authorization: Bearer $TOKEN" \
  -H "Idempotency-Key: 7c9e6679-…" \
  -d '{ "amount": 5820, "currency": "USD", "merchant_id": "mch_demo", "pan_token": "tok_9d1b4e", "entry_mode": "contactless" }'
const auth = await dgn.authorizations.create({
  amount: 5820, currency: "USD", merchantId: "mch_demo",
  panToken: "tok_9d1b4e", entryMode: "contactless"
});
auth = client.authorizations.create(
  amount=5820, currency="USD", merchant_id="mch_demo",
  pan_token="tok_9d1b4e", entry_mode="contactless")
Response
{ "id": "auth_71ab3c", "decision": "approved", "response_code": "00",
  "approved_amount": 5820, "avs": { "street": "Y", "postal": "Y" },
  "score": 22, "answered_by": "issuer", "issuer_ms": 41,
  "request_id": "req_71ab00", "round_trip_ms": 44 }
Try it
POST/acceptance/v1/authorizations/{id}/reverse

Reverse an authorization

Release a hold you no longer need, in full or in part. The issuer sees it immediately.

What you send

amountintegerOptional

Minor units. Omit to reverse the full hold.

Request
curl -X POST https://sandbox.api.dgn.com/acceptance/v1/authorizations/auth_71ab3c/reverse \
  -H "Authorization: Bearer $TOKEN" -H "Idempotency-Key: …" -d '{ "amount": 5820 }'
await dgn.authorizations.reverse("auth_71ab3c", { amount: 5820 });
client.authorizations.reverse("auth_71ab3c", amount=5820)
POST/acceptance/v1/captures

Capture

Move an approved hold into the day's clearing file. Within 7 days. Accepts a batch of up to 5,000 ids.

What you send

authorization_idstringRequired

Or authorization_ids, an array, for a batch.

amountintegerOptional

Minor units. Up to approved_amount. Omit for the full hold.

Request
curl -X POST https://sandbox.api.dgn.com/acceptance/v1/captures \
  -H "Authorization: Bearer $TOKEN" -H "Idempotency-Key: …" \
  -d '{ "authorization_id": "auth_71ab3c", "amount": 5820 }'
await dgn.captures.create({ authorizationId: "auth_71ab3c", amount: 5820 });
client.captures.create(authorization_id="auth_71ab3c", amount=5820)
POST/acceptance/v1/refunds

Refund

Return captured money to the cardholder. Full or partial. Reaches the cardholder in 3 to 5 days.

What you send

authorization_idstringRequired

The captured authorization.

amountintegerOptional

Minor units. Omit for the full capture.

reasonenumOptional

requested_by_customer, duplicate, fraudulent.

Request
curl -X POST https://sandbox.api.dgn.com/acceptance/v1/refunds \
  -H "Authorization: Bearer $TOKEN" -H "Idempotency-Key: …" \
  -d '{ "authorization_id": "auth_71ab3c", "amount": 2000, "reason": "requested_by_customer" }'
await dgn.refunds.create({ authorizationId: "auth_71ab3c", amount: 2000, reason: "requested_by_customer" });
client.refunds.create(authorization_id="auth_71ab3c", amount=2000, reason="requested_by_customer")

Tokens

The Token object

A card number replaced with a token scoped to one merchant. Kept current when the card is reissued; token.updated says so.

POST/tokens/v1/tokens

Create a token

Replace a card number with a merchant-scoped token. A token stolen from one merchant is useless at another.

What you send

panstringRequired

The card number. Never stored by the network beyond tokenization.

merchant_idstringRequired

Scopes the token.

expirystringRequired

YYYY-MM.

Request
curl -X POST https://sandbox.api.dgn.com/tokens/v1/tokens \
  -H "Authorization: Bearer $TOKEN" -H "Idempotency-Key: …" \
  -d '{ "pan": "6011330000000005", "expiry": "2028-04", "merchant_id": "mch_demo" }'
const tok = await dgn.tokens.create({ pan, expiry: "2028-04", merchantId: "mch_demo" });
tok = client.tokens.create(pan=pan, expiry="2028-04", merchant_id="mch_demo")
Response
{ "id": "tok_9d1b4e", "merchant_id": "mch_demo", "last4": "0005", "expiry": "2028-04", "status": "active" }

Disputes

The Case object

A retrieval, chargeback or arbitration against one authorization. Carries the reason code and the response deadline.

idstring

dsp_ followed by three hex characters.

stageenum

retrieval, chargeback, arbitration.

reason_codestring

4837 not authorized, 4853 not as described, 4855 not received, 4860 credit not processed.

respond_bydatetime

Missing it loses the case.

statusenum

needs_response, under_review, won, lost, accepted.

POST/disputes/v1/cases/{id}/evidence

Submit evidence

Upload the merchant's evidence. The network formats it for the issuer and tracks the clock. One file per evidence type; links and media are not reviewed.

What you send

product_typeenumRequired

physical, digital, subscription. Sets which evidence is asked for.

filesarrayRequired

Each with type (proof_of_delivery, order_page, correspondence, terms) and a PDF or image up to 10 MB.

notestringOptional

Shown to the issuer, not the cardholder.

Request
curl -X POST https://sandbox.api.dgn.com/disputes/v1/cases/dsp_41e/evidence \
  -H "Authorization: Bearer $TOKEN" \
  -F product_type=physical -F "files[]=@delivery.pdf;type=proof_of_delivery"
await dgn.disputes.submitEvidence("dsp_41e", { productType: "physical", files: [{ type: "proof_of_delivery", path: "delivery.pdf" }] });
client.disputes.submit_evidence("dsp_41e", product_type="physical", files=[("proof_of_delivery", open("delivery.pdf","rb"))])

Settlement reports

GET/money/v1/settlements/{date}

A day's cycle

Gross, fees, adjustments, net, and the wire that carried it. Published by 5:00 AM local. Minor units, settled before fees.

Request
curl https://sandbox.api.dgn.com/money/v1/settlements/2026-06-02 -H "Authorization: Bearer $TOKEN"
const cycle = await dgn.settlements.retrieve("2026-06-02");
cycle = client.settlements.retrieve("2026-06-02")
Response
{ "id": "stl_0602", "date": "2026-06-02", "gross": 16421000, "fees": 180600,
  "adjustments": -129000, "net": 15890400, "wire": "FW-2026-0602-4471", "status": "posted" }

Decisioning

The Decision object

The network's risk score on one authorization and the factors that moved it. The score and its reasons also ride on the Authorization object; this is the long form.

GET/decisioning/v1/decisions/{id}

Explain a decision

Every factor behind the score on one authorization, with its effect. Read it or ignore it; nothing you send changes.

What you send

idstringRequired

An authorization id, in the path.

What comes back

A Decision object. score is 0 to 100; band is low, elevated or high; each factor carries its effect on the score.

Request
curl https://sandbox.api.dgn.com/decisioning/v1/decisions/auth_71ab3c -H "Authorization: Bearer $TOKEN"
const decision = await dgn.decisions.retrieve("auth_71ab3c");
decision = client.decisions.retrieve("auth_71ab3c")
Response
{ "authorization": "auth_71ab3c", "score": 22, "band": "low",
  "factors": [ { "name": "token_scope_match", "effect": -9 }, { "name": "merchant_history_180d", "effect": -6 }, { "name": "cross_border", "effect": 3 } ],
  "model": "dgn-risk-4" }

Events

Sent to an endpoint you register, signed on every delivery, retried for three days. How to receive them.

EventWhenCarries
authorization.decisionedWithin a second of every decisionThe Authorization object
dispute.openedWhen a cardholder disputes a transactionThe Case object, with respond_by
settlement.postedWhen a cycle is final, by 5:00 AM localThe Settlement object, with the wire reference
token.updatedWhen the issuer reissues a tokenized cardThe Token object; the id does not change
merchant.risk_changedWhen a merchant moves outside its own baselinemerchant_id, the metric, the baseline and the value
certificate.expiring30 days before a certificate the network reads on your handshake expires, and again at 7The certificate's subject, environment and expiry
