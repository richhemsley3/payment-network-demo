Basics

Authentication

Every call carries a bearer token from your client id and secret, valid for one hour. Mutual TLS is required in certification and production. One set of credentials is promoted through the environments by the network.

curl -X POST https://sandbox.api.dgn.com/oauth/token -u "$DGN_ID:$DGN_SECRET" -d grant_type=client_credentials
# { "access_token": "…", "token_type": "bearer", "expires_in": 3600 }
const dgn = new Network({ clientId, clientSecret, env: "sandbox" }); // refreshes for you
client = dgn.Network(client_id=..., client_secret=..., env="sandbox")

The envelope

JSON over HTTPS. Amounts are integers in minor units. Times are RFC 3339 in UTC. Every response carries request_id and round_trip_ms. Ids are prefixed by object.

Idempotency

Send Idempotency-Key on any POST. The same key within 24 hours returns the original response. A key in flight returns 409. One key per attempt on your side. Errors and idempotency.

The header
POST /acceptance/v1/authorizations
Idempotency-Key: 7c9e6679-7425-40de-944b-e07fc1f90ae7

# the same key again within 24 hours
HTTP/1.1 200 OK
Idempotent-Replayed: true

Errors

Two kinds of answer. A decline is a 200 with a response_code. A request that could not be processed is a 4xx or 5xx with type, message and request_id. Look a code up here, or read when to retry.

Versioning

The version is in the path. Supported for 24 months after its successor ships. Additive changes are announced in the changelog without a version change. Calls to a retired version return 410.

The path
/acceptance/v1/…   v4, current
/acceptance/v3/…   retires February 28, 2028, then 410

Pagination

Lists return up to 100 objects and a next_cursor. Pass it as cursor to continue. Lists are newest first. An empty next_cursor is the last page.

A page
GET /disputes/v1/cases?limit=100&cursor=dsp_41e

Events

Sent to an endpoint you register, over mutual TLS, signed on every delivery, and retried for three days. Answer 2xx within 10 seconds, then do the work. Deliveries are at least once, so handle the same event id twice. How to receive them.
