The CLI

Send requests to the sandbox, tail your webhook deliveries, and forward events to a handler on your machine without registering a URL.

Install and log in
npm install -g @dgn/cli
dgn login                      # opens the portal to grant a sandbox key
dgn authorizations create --amount 5820 --currency USD --card 6011330000000005
dgn events listen --forward-to localhost:4000/dgn/events
