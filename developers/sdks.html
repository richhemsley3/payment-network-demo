Reference

SDKs and tools

A library for each of five languages, installed and making its first call in one sample. A CLI for the sandbox. The OpenAPI document and a Postman collection.

Libraries

Each library exposes every endpoint in the reference, exchanges and refreshes the token, sets Idempotency-Key when you do not, and retries what the network says to retry.

The CLI

Send requests to the sandbox, tail your webhook deliveries, and forward events to a handler on your machine without registering a URL. Four commands from nothing to a delivery.

OpenAPI and Postman

OpenAPI 3.1

Every endpoint, object and event, versioned with the API. Generate your own client.

Postman collection

Environments for sandbox and certification, credentials read from variables.

Sample applications

Three applications that run against the sandbox on your own sandbox key. The columns say which calls each one makes.

Each sample ships in the repository with its SDK.
