# The Story of Brightline Bank — demo

A packaged, static copy of the demo: the ten-panel story prototype, the public
developer site it links to, and the stylesheet both run on. Open `index.html`,
or serve the folder with any static server. Nothing here is edited by hand: it
is produced by `tools/package-demo.sh` in the working repository.

Every figure, name, participant and API in it is invented.
